# Research_Agent_AI

Research_Agent_AI is a modular, LLM-powered equity research engine designed
to generate long-term 7-step research reports, tactical near-term 7-step
reports, and comprehensive hybrid reports.

## Status — read this first

This repository currently contains the product's licence, its product terms,
and this description. **The engine's source code is not published in this
repository.** There is nothing to install or run from this repository today;
the sections below describe only what is actually here, and this README will
gain real install and usage instructions when the source is published.

## What the engine is designed to produce

- **Long-Term 7-Step Research Reports**
- **Tactical Near-Term 7-Step Reports**
- **Comprehensive Hybrid Reports**
